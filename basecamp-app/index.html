Private M-of-N Multisig

Live multisig state, member commitment derivation, and vote commands. Member NSKs never leave this page.

1 — Multisig state (live)

Reads the account via getAccount and decodes the Borsh state client-side. Shows the threshold, member count, and each proposal's votes / nullifiers / executed flag — never who voted.
