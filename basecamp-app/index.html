2 — Vote

    
Use the multisig vote CLI command to generate a receipt offline, then submit it via the chain interface.

    
multisig vote \
  --nsk <NSK> \
  --member-index <N> \
  --multisig-id <ID> \
  --proposal-id <ID> \
  --member-commitments <c0,c1,...> \
  --out vote-receipt.bin
